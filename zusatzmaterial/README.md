# Zusatzmaterial

Hier können ergänzende, nicht zur Produktquelle gehörende Materialien abgelegt werden.

- `screenshots/`: Sichtprüfungen, Fehlerbilder und Vergleichsaufnahmen; bitte nach Datum oder Version untergliedern
- `importe/`: PPTX- und andere Dateien, die zum Testen oder als Inhaltsquelle dienen
- `referenzen/`: visuelle, fachliche oder technische Referenzen
- `notizen/`: freie Begleitnotizen

Empfohlene Benennung: `V0_0XX_YYYYMMDD-kurze-beschreibung.ext`. Große Binärdateien werden lokal aufbewahrt und über Inventare beziehungsweise Hashes nachgewiesen, nicht regulär in Git gespeichert.
